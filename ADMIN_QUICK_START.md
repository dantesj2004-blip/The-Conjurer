# ⚡ INICIO RÁPIDO - Panel de Administración

## 🚀 En 5 Minutos

### 1. Abre tu navegador
```
http://localhost/The-Conjurer/
```

### 2. Inicia sesión como admin
```
Email: admin@theconjurer.com
Contraseña: admin123
```

### 3. Ve a "Mi Perfil"
```
Botón arriba a la derecha después de login
```

### 4. Haz clic en "Panel de Control"
```
Verás el nuevo panel profesional
```

### 5. ¡Comienza a usar!
```
- Ve a Noticias para crear/editar/eliminar
- Ve a Cartas para gestionar cartas
- Ve a Usuarios para administrar accounts
```

---

## 📌 Lo Más Importante

### ✅ Panel Centralizado
```
http://localhost/The-Conjurer/admin_panel.html
```

### ✅ Sidebar Navegación
- 📊 Dashboard - Vista general
- 📰 Noticias - Gestionar news
- 🎴 Cartas - Gestionar cartas
- 👥 Usuarios - Gestionar users

### ✅ 3 Acciones Principales
1. **CREAR** - Botones "Nueva Noticia" / "Nueva Carta"
2. **EDITAR** - Botones "Editar" en cada fila
3. **ELIMINAR** - Botones "Eliminar" en cada fila

---

## 📊 Ejemplos Rápidos

### Crear Noticia
```
1. Click "Noticias" en sidebar
2. Click "Nueva Noticia"
3. Rellena: Título, Fecha, Contenido
4. Click "Guardar Noticia"
```

### Editar Carta
```
1. Click "Cartas" en sidebar
2. Encuentra la carta en tabla
3. Click "Editar"
4. Modifica campos
5. Click "Guardar Carta"
```

### Promover Usuario
```
1. Click "Usuarios" en sidebar
2. Busca usuario en lista
3. Click "Hacer Admin"
4. Confirma
```

---

## 🔐 Importante

- ⚠️ Solo admins pueden acceder
- ⚠️ No hay papelera, las eliminaciones son permanentes
- ⚠️ Confirma antes de eliminar
- ⚠️ No puedes eliminar tu propia cuenta
