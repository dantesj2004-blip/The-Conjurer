Test - Sistema Completo de Referencias

Guía para validar que cartas y mazos se muestran y se pueden importar correctamente

1. Verificar Base de Datos

Base de Datos: the_conjurer

Tablas requeridas:

  • cartas - Con campos: ID, Nombre, Tipo, Mitologia, Fuerza, Coste, Imagen, Era
  • noticias - Con campos: id, titulo, fecha, contenido, imagen_url
  • noticia_referencias - Referencias de cartas/mazos en noticias
  • mazos - Con campos: id, usuario_id, nombre, mitologia, mazo_data
  • usuarios - Con campo es_admin

SQL Ejecuta en PhpMyAdmin:

DESCRIBE cartas;
SELECT COUNT(*) FROM cartas;

2. Verificar Imágenes de Cartas

Ruta de Imágenes

Estructura esperada:

/The-Conjurer/GDM/Era I-IV/Tipo/NombreCarta.jpg
/The-Conjurer/GDM/Era II/Tipo/NombreCarta.jpg
/The-Conjurer/GDM/Era III/Tipo/NombreCarta.jpg

CHECK En BD tabla cartas, campo Imagen debe contener:

/GDM/Era I-IV/Acciones/CartaNombre.jpg

El endpoint get_all_cards_list.php convierte automáticamente a:
/The-Conjurer/GDM/Era I-IV/Acciones/CartaNombre.jpg

3. Test de Búsqueda de Cartas en Admin

1Abre Admin Panel

Abrir Admin Panel

Debe estar logueado como admin

2Crear o Editar Noticia

Click "Crear Noticia" o editar una existente

✓ Debes ver sección "Insertar Cartas"

3Buscar Carta

En campo de búsqueda, escribe: fuego, mago, o cualquier nombre de carta

✓ Resultados aparecen al escribir 2+ caracteres

✓ Máximo 30 cartas se muestran

4Click en Resultado

Click en una carta de la lista

✓ Item se destaca con fondo verde

✓ Aparece "✓ CARTA SELECCIONADA" en preview derecho

5Verificar Imagen

CRÍTICO En el preview debe aparecer la imagen de la carta

Si NO aparece:

  • Abre Consola (F12) → Console
  • Busca logs: "Imagen URL: ..." y "Imagen no disponible"
  • Verifica ruta en BD: SELECT Imagen FROM cartas LIMIT 1;
  • Intenta cargar imagen directa en navegador

6Agregar a Noticia

Click botón "Agregar a Noticia"

✓ Carta aparece en grid inferior

✓ Grid muestra imagen y datos de la carta

4. Test de Mazo en Noticia

1Agregar Mazo

En admin panel, sección "Insertar Mazo":

✓ Dropdown muestra tus mazos existentes

✓ Click en uno para ver preview

2Mazo Preview

En preview debe mostrarse:

  • ✓ Nombre del mazo (negrita)
  • ✓ Mitología
  • ✓ Total de cartas
  • ✓ Banner "✓ MAZO SELECCIONADO"

3Guardar Noticia

Agrega referencia y guarda noticia

5. Test de Notica Pública - Ver Referencias

1Abrir Noticia

Ir a Noticias

Click en una noticia que creaste con referencias

2Sección Cartas Mencionadas

Scroll hacia abajo

✓ Debe haber título "Cartas Mencionadas"

✓ Grid con cartas (imagen, nombre, mitología, coste)

✓ Imágenes se cargan correctamente

✓ Hover: zoom 1.05x efecto visual

3Sección Mazos Mencionados

CRÍTICO Debe haber título "Mazos Mencionados"

Contenido del Mazo:

  • Header con: Nombre mazo | Mitología | Total cartas
  • Lista scrollable de cartas con:
    • Cantidad en verde: x1, x2, x3
    • Nombre de la carta
    • Mitología (gris)
    • Imagen miniatura 40x56px a la derecha
  • Botón "Guardar Mazo en Mi Perfil" en verde

6. Test - Importar Mazo

1Estar Logueado

Verifica que tu sesión esté activa (Usuario mostrado arriba)

Si NO: Ir a Login

2Click Botón Importar

En noticia con mazo, click en "Guardar Mazo en Mi Perfil"

✓ Sistema verifica sesión

✓ Obtiene datos del mazo desde servidor

✓ Guarda a tu perfil

3Feedback Visual

Botón debe cambiar a:

Mazo Guardado!

✓ Luego vuelve a normal después de 2s

✓ Aparece alert: "Mazo guardado exitosamente!"

4Verificar Guardado

Ve a tu Perfil → Mazos

✓ Nuevo mazo aparece con nombre "(Importado)"

✓ Puedes verlo en Deckbuilder

7. Endpoints - Validación Técnica

Método Endpoint Descripción Respuesta Esperada
GET /get_all_cards_list.php Lista de todas las cartas {"cartas": [{id, nombre, imagen, ...}]}
GET /get_noticia_referencias_detalles.php?noticia_id=X Referencias de una noticia {"referencias": [...], "cartas": {...}, "mazos": {...}}
GET /get_mazo_para_importar.php?mazo_id=X Datos completos del mazo {"id, nombre, mitologia, mazo_data}
POST /save_imported_mazo.php Guardar mazo a perfil {"success": true, "mazo_id": X}

8. Debuggeo en Console

Abrir Console (F12)

Esperarás ver logs como:

Cartas cargadas: 350
Mostrando preview de carta: {...}
Imagen URL: /The-Conjurer/GDM/... Tiene imagen: true
Imagen cargada exitosamente: /The-Conjurer/GDM/...
Referencias cargadas: {...}

Si ves errores:

  • Error 403 → Usuario no es admin
  • no hay cartas cargadas → BD vacía o error en fetch
  • Imagen no disponible → Ruta de imagen incorrecta en BD
  • CORS error → Problema de servidor
